# UkiddGj — Personal Portfolio

A responsive Apple-inspired Bento Grid portfolio using plain HTML, CSS and JavaScript. No build step or dependencies.

## Publish on GitHub Pages
1. Create a public repository named `ukiddnagata.github.io` under your GitHub account.
2. Upload `index.html`, `style.css`, and `script.js` to the root of the main branch. Commit the files.
3. Open Settings → Pages. Under Build and deployment select Deploy from a branch, main, and / (root). Save.
4. After GitHub finishes deployment, visit https://ukiddnagata.github.io/.

## Customize
- The profile image loads from your public GitHub avatar. To use a local image, upload `profile.jpg` and change the image src in index.html to `profile.jpg`.
- Edit project descriptions, personal details and links in index.html. The three IoT/network project cards are descriptive and do not claim public repositories exist.
- Theme variables are at the top of style.css. Dark mode is the default; the toggle saves the selected mode locally.
- No email, phone number or social media handles were invented. Add them if desired.
